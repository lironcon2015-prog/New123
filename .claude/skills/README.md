# סקילז של הפרויקט

סקילז שנשמרים כאן נטענים אוטומטית בכל סשן של Claude Code — מקומי, ווב או אפליקציה.
זו הסיבה שהם יושבים בריפו ולא מותקנים דרך `npx skills`: התקנה גלובלית נמחקת עם
הקונטיינר, והכנסה לריפו שורדת.

## מה יש כאן

| סקיל | מה הוא עושה | הפעלה |
| --- | --- | --- |
| `apple-design` | עקרונות התנועה והעיצוב של אפל, מתורגמים לוובּ | `/apple-design` |
| `emil-design-eng` | הפילוסופיה של Emil Kowalski על ליטוש ממשק ופרטים קטנים | `/emil-design-eng` |

שניהם נטענים גם לבד כשהשיחה עוסקת בעיצוב או בתנועה.

## מקור

הועתקו כלשונם מ-<https://github.com/emilkowalski/skills> תחת רישיון MIT.
נוסח הרישיון נמצא ב-`LICENSE` שליד. הקבצים לא שונו — עדכון נעשה בהעתקה מחדש
מהמקור, לא בעריכה מקומית.

התוכן של `apple-design` הוא סיכום של הרצאות העיצוב הפומביות של אפל ב-WWDC.
הוא לא פורסם על ידי אפל.

## אזהרה לשימוש בפרויקט הזה

שני הסקילז נכתבו מתוך הנחה של React עם Motion או Framer Motion. הרעיונות
עצמם אגנוסטיים ועובדים ב-CSS נקי, אבל **קטעי הקוד שבהם מפרים את אילוצי
הפרויקט** — ראו `CLAUDE.md`: ללא build, ללא framework, ללא תלויות.

לכן בכל הפעלה יש לציין את האילוץ במפורש:

```
/apple-design תעבור על מסך רשימת המסמכים. Vanilla JS ו-CSS בלבד, בלי ספריות.
```

הצעה שמגיעה מהסקיל וכוללת ספרייה חיצונית — נדחית. האילוצים ב-`CLAUDE.md`
גוברים על כל סקיל.
