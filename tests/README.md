# בדיקות עשן

שתי סוויטות Playwright שמריצות את רשימת ה"בוצע" של שלב 3 (`docs/SPEC.md` §9) מול הדפדפן.
הן **אינן חלק מהאפליקציה**: אין `package.json` בשורש, ואף קובץ כאן לא נטען בזמן ריצה.
האילוץ "ללא build" (§1 באפיון) חל על האפליקציה, לא על מה שבודק אותה.

## הרצה

```bash
npm i playwright                       # פעם אחת, מחוץ לריפו
python3 -m http.server 8777            # IndexedDB לא עובד מעל file://
node tests/e2e.mjs                     # 52 בדיקות — זרימות מקצה לקצה
node tests/units.mjs                   # 34 בדיקות — ולידטורים, נרמול, טוהר הטבלה
```

משתני סביבה: `BASE` (ברירת מחדל `http://127.0.0.1:8777/index.html`), `CHROME` (נתיב לדפדפן),
`FIXTURES` (תיקייה עם `shot.png` ל-`e2e.mjs`).

## מה נבדק

**`e2e.mjs`** — יצירת ישות · מסמך ידני מכל 12 הסוגים · העתקה בנגיעה כולל שורה ממוסכת
(מוודא שהערך המלא נכנס ללוח ושהמסך לא נחשף) · שדה שנכשל בוולידציה נשמר ומסומן ·
חיפוש גלובלי · ארבעת מסלולי הקלט · דליי התפוגה כולל `daysLeft === 0` · חישוב חוצה שעון קיץ ·
התמדה אחרי רענון · החלפת פלטה וכתב · שער PIN מקצה לקצה כולל כיבוי · אפס שגיאות קונסול.

**`units.mjs`** — ספרת ביקורת של ת״ז · פורמט לוחית 7 ו-8 ספרות · תאריכים · טלפון ·
מיסוך · `copyAs` · נרמול תמונות בארבעה מקרים כולל הכלל שנרמול לא מגדיל קובץ ·
דחיית קובץ שבור · **אפס בקשות לדומיין חיצוני** · **`screens.js` ו-`forms.js` אינם מזכירים
אף מפתח סוג מסמך** — זו הבדיקה ששומרת על הכלל הארכיטקטוני של `DOC_TYPES`.
